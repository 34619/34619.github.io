# 黑暗生存 Darkness Survival — 游戏设计文档

## 概述

**类型**：暗黑系 Roguelike 地牢生存冒险
**平台**：Unity（iOS + Android）
**视角**：2D 俯视角
**美术风格**：手绘暗黑哥特风
**参考**：原作《黑暗生存》(Zero++ Software)

玩家扮演一位女孩，被困在无尽的地下迷宫地牢中。在黑暗中探索、战斗、收集资源、制作装备，寻找出口深入更深层。每次死亡从头来过，但收集的符文配方永久保留。

## 设计支柱

1. **黑暗压迫感**：大面积黑暗遮罩，有限视野制造紧张氛围
2. **生存紧迫感**：HP/饥饿/口渴三维系统驱动持续探索
3. **发现惊喜感**：随机地图、随机掉落、配方解锁
4. **死亡循环**：永久死亡 + 配方保留 = 每次都更进一步

## 核心循环

```
30秒: 探索房间 → 遭遇敌人/资源 → 战斗/采集 → 获得掉落
3分钟: 收集材料 → 制作食物/装备 → 应对更强敌人 → 寻找楼梯
30分钟: 深入多层 → 积累符文配方 → 挑战Boss → 死亡或通关
```

## 玩家属性

| 属性 | 说明 | 初始值 |
|------|------|--------|
| HP | 生命值，归零死亡 | 30 |
| ATK | 攻击力（基础+装备） | 5 |
| DEF | 防御力（基础+装备） | 4 |
| 饥饿值 | 每步-2，归零扣HP | 100 |
| 口渴值 | 每步-3，归零扣HP | 100 |
| 体温 | 每步-0.5，归零扣HP | 37°C |
| 等级 | 击杀怪物获得EXP升级 | 1 |
| 视野 | 基础3格，火把/灯笼增加 | 3 |

## 等级系统

- 经验公式：`20 × 1.5^(level-1)`
- 升级效果：+5 MaxHP, +5 HP, +2 ATK, +1 DEF

## 地牢生成

- **算法**：递归回溯（Recursive Backtracker）
- **结构**：迷宫走廊 + 随机额外通道
- **尺寸**：每层递增（15×15 → 40×40）
- **楼层定义**：

| 楼层 | 尺寸 | 怪物数 | Boss | 商店 | 精英 | 描述 |
|------|------|--------|------|------|------|------|
| 1 | 15×15 | 3-5 | 否 | 否 | 否 | 阴暗地牢入口 |
| 2 | 18×18 | 5-8 | 是 | 否 | 否 | 骷髅走廊 |
| 3 | 20×20 | 6-10 | 否 | 是 | 否 | 地下集市 |
| 4 | 22×22 | 8-12 | 是 | 否 | 是 | 精英要道 |
| 5 | 25×25 | 10-15 | 否 | 否 | 是 | 珍稀矿脉 |
| 6 | 28×28 | 12-15 | 是 | 是 | 是 | 恶魔领地 |
| 7+ | 动态 | 动态 | 每2层 | 每3层 | 始终 | 深渊未知 |

- **难度缩放**：怪物属性倍率 = `1 + (floor-1) × 0.3`
- **Boss倍率**：`1 + (floor-1) × 0.5`

### 精英怪物
- 20% 概率追加攻击
- 更高掉落率

### Boss
- 每2层出现
- 特殊技能：重击、AOE、回血、减防
- 掉落传说装备

## 战斗系统

回合制，4种行动：
- **攻击**：`max(1, ATK - 敌方DEF)` 伤害
- **蓄力**：下次攻击 1.5x 伤害
- **防御**：本回合受伤害减半
- **逃跑**：40% 成功概率

## 装备系统

### 装备槽位（8个）
- 武器（剑/枪/斧/魔法）
- 盔甲
- 头盔
- 盾牌
- 鞋子
- 戒指
- 项链
- 腰带/翅膀

### 装备品质
- 普通（白色）→ 精良（绿色）→ 稀有（蓝色）→ 史诗（紫色）→ 传说（橙色）

### 词缀系统（后续扩展）
- 前缀：锋利(+ATK)、坚固(+DEF)、迅捷(+速度)
- 后缀：吸血、火焰伤害、冰冻减速

### 配方解锁
- 初始解锁：面包、草药汤、火把
- 击杀掉落：击败Boss/精英概率解锁新配方
- 配方永久保留（跨死亡）

## 生存机制

| 维度 | 每步消耗 | 归零惩罚 | 恢复方式 |
|------|----------|----------|----------|
| 饥饿 | -2 | HP-3/步 | 面包、烤肉、草药汤 |
| 口渴 | -3 | HP-5/步 | 清水 |
| 体温 | -0.5 | HP-4/步 | 热汤 |

## 商店系统

- 分3档：Tier 1(1-2层)、Tier 2(3-4层)、Tier 3(5+层)
- 货币：金币（击杀掉落）

## 生存日记

- 每步记录事件（遭遇、掉落、制作、升级）
- 关键事件有叙事文本（"你在食物中发现一颗红色宝石"）
- 死亡后展示日记回顾

## UI 设计

### 主界面
- 中央：Canvas 地牢渲染
- 顶部：HP/饥饿/口渴/体温状态栏
- 左侧：事件日志
- 底部：背包/制作/商店/属性按钮

### 战斗界面
- 敌人信息 + HP条
- 玩家信息 + HP条
- 战斗日志
- 行动按钮：攻击/蓄力/防御/逃跑

### 背包界面
- 6×4 格子背包
- 8个装备槽位
- 物品详情面板
- 装备/使用/丢弃按钮

## 技术方案

- **引擎**：Unity 2D
- **语言**：C#
- **数据驱动**：ScriptableObject 存储物品/怪物/配方
- **地图**：Tilemap 系统
- **光照**：2D Light + Shadow Caster（黑暗遮罩）
- **UI**：Unity UI (uGUI)
- **存储**：JSON 序列化 + PlayerPrefs
